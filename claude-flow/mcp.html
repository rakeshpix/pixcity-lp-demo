MCP protocol

Claude

MCP client + model reasoning — calls tools, reads resources, responds

1. Understands

Reads the request & the MD instructions/memory for context

2. Decides

Picks which tool to call — get_contract_details to check, create_projects to act

3. Acts

Calls the tool via MCP, repeats per item, reports back

End-user flow — example

"I have a 12-month contract — create a community management project for each month, spaced out by each delivery date."

1. Request

User asks Claude

"Create 12 monthly community management projects for this contract"

2. Context

get_contract_details

Returns start/end dates and the quote's line items & volumes for the contract

3. Plan

Claude calculates dates

Works out the gap between each delivery date to schedule 12 projects, one per month, with the right items & volumes

4. Tool calls

create_projects ×12

One MCP tool call per project, each with its own delivery date and requirements

5. Result

Backoffice updated

12 projects now exist, spaced correctly — Claude confirms to the user
