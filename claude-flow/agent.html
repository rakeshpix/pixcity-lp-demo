End-user flow — example

"I have a 12-month contract — create a community management project for each month, spaced out by each delivery date."

1. Request

Backoffice calls the Agent

Sends the contract's start/end dates and quote line items & volumes — no separate lookup needed, Backoffice already has this

2. Skill applied

Agent reasons over the contract

Uses its predefined skill to interpret the delivery cadence and contract terms

3. Plan generated

12 monthly projects defined

Each with its own delivery date and item/volume metadata, spaced by the gap between deliveries

4. Response returned

Single structured response

One API call, one reply — the full 12-project plan as structured JSON, no tool loop

5. Projects created

create_projects() ×12

Backoffice's own method writes all 12 projects — the agent never touches the database
